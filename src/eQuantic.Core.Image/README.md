# eQuantic.Core.Image

Image manipulation for .NET on an engine of its own: decoding and encoding, metadata, transforms,
web optimization and effects, in managed code, with no native or third-party dependency.

> **Status: under construction.** This package has no public API yet. The design and the roadmap are
> in the [repository](https://github.com/eQuantic/core-image).
